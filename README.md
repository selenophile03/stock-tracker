#  - Stock Tracker Portfolio Dashboard

A lightweight tracking framework engine configured to watch inventory position holdings with local client state persistence.

## ✨ Features
* **Dynamic Profit & Loss Calculation**: Real-time evaluation metrics comparing current execution rates against entry costs.
* **Smart Asset Consolidation**: Submitting an existing ticker updates the inventory size using weighted arithmetic moving average costs.
* **Persistent Cache Engine**: Positions survive clean app restarts using client browser `localStorage`.

## 🚀 Quick Setup Instructions
1. Clone this repository locally.
2. Launch `index.html` via any modern web browser or live server module.
